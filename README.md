# TalentLens AI

TalentLens is an AI powered resume analysis platform designed to help candidates understand how well their resume matches a given job description.

The platform analyzes resume content, extracts relevant information, and will provide a compatibility score along with insights into matching and missing skills.

## Project Status

**Currently in development**

The current version focuses on the resume processing pipeline:

- PDF resume upload
- PDF text extraction
- Text cleaning
- Resume section detection
- PostgreSQL persistence
- Frontend and backend integration

AI-powered skill extraction, semantic matching, and compatibility scoring are planned for the next stages.
