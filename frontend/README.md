### Frontend

- **Framework:** Next.js 16 (App Router)
- **UI & Styling:** React, Tailwind CSS v4, Lucide React
- **Analysis:** Runs fully in the browser — PDF.js, IndexedDB, Transformers.js (MiniLM), and a TypeScript port of the matching engine
- **Deploy:** Vercel (or any static/Next host). No `NEXT_PUBLIC_API_URL` required.

```bash
npm install
npm run dev
```
